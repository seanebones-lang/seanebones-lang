### [Deadbolt](https://github.com/seanebones-lang/deadbolt) — execution controls for software agents

Built a Rust admission gate with embedded, HTTP, and stdio MCP integration paths, operator revocation, and structured evidence. Published native releases for macOS, Linux, and Windows. Documented consumer tests exercise permitted and denied actions, outages, and recovery. Enforcement depends on the application's trusted dispatcher checking before execution. Apache-2.0 licensed.

### [Harness](https://github.com/seanebones-lang/harness) — Rust work assistant

Built a provider-neutral runtime with explicit model routing, repository tools, persistent sessions, bounded workers, terminal and local web interfaces, and MCP support. The [acceptance record](https://github.com/seanebones-lang/harness/blob/main/docs/PERSONAL_USE.md) links cross-platform CI and distinguishes synthetic checks from live provider behavior. MIT licensed; current development focuses on dependable personal use.

### [Repo Salvage](https://github.com/seanebones-lang/repo-salvage) — source discovery and reuse tooling

Built a TypeScript/Next.js application, agent API, CLI, and local MCP adapter around pinned source, provenance, license notices, and reviewable component briefs. Controlled evaluations include fresh consumer integrations and recorded failures. A working development prototype; independent usefulness and demand remain unproven.
