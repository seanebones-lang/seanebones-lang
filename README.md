## Key Projects

### [harness](https://github.com/seanebones-lang/harness)
Production-grade terminal AI coding agent written in Rust. Includes MCP support, semantic memory, multi-provider architecture (xAI, Anthropic, Ollama), and a high-performance TUI. Built for serious engineering use cases.

### [InkLine-Pro](https://github.com/seanebones-lang/InkLine-Pro)
AI-powered React Native application that generates professional tattoo linework from text or photo references using Grok + Hugging Face models.

### [trailerguard](https://github.com/seanebones-lang/trailerguard)
Mobile platform for trailer and fleet operations featuring BLE tire pressure monitoring, immutable mileage tracking, and real-time alerting. Built with React Native + Supabase.

### [probable-fishstick](https://github.com/seanebones-lang/probable-fishstick)
Local-first Personal RAG system. Ingests personal data (emails, chats, documents, code), embeds with lightweight CPU models, and enables natural language querying using Ollama.

### [web-part-two](https://github.com/seanebones-lang/web-part-two)
NextEleven marketing site with Sanity CMS and an integrated Grok-powered AI chat widget.

Additional client work and private AI/agent projects available on request.
